##  โครงสร้างโปรเจกต์ (Project Structure)

```text
├── index.html   # โครงสร้างหน้าเว็บและข้อมูลตาราง (Semantic HTML)
├── style.css    # สไตล์และเลย์เอาต์ทั้งหมด (Pure CSS)
└── README.md    # เอกสารประกอบการติดตั้งและใช้งาน
```

---

##  วิธีการรันโปรเจกต์ (How to Run)

รันผ่าน VS Code Live Server
1. เปิดโฟลเดอร์โปรเจกต์ด้วย [Visual Studio Code]
2. ติดตั้ง Extension ที่ชื่อว่า **Live Server** (โดย Ritwick Dey)
3. คลิกขวาที่ไฟล์ `index.html` แล้วเลือก **Open with Live Server**
